# KHRECOM Randomizer

The core mod for the Kingdom Hearts Re:Chain of Memories Archipelago Randomizer. It runs on
[OpenKH](https://github.com/OpenKH/OpenKh/)'s Lua Backend. Seed-specific settings come from a seed mod generated by
Archipelago (the same way [KH1-RANDOMIZER](https://github.com/gaithern/KH1-RANDOMIZER) works), and items and checks
pass through files in `%LOCALAPPDATA%\KHRECOM\` shared with the KHRECOM Archipelago client. This replaces
[KH-RECOM-AP-LUA](https://github.com/gaithern/KH-RECOM-AP-LUA), rewritten on top of
[KHRECOM-LUA-LIBRARY](https://github.com/gaithern/KHRECOM-LUA-LIBRARY).

## Requirements
- [KHRECOM-LUA-LIBRARY](https://github.com/gaithern/KHRECOM-LUA-LIBRARY) installed and enabled alongside this mod.
- The seed mod from Archipelago generation, installed alongside this mod.
- The KHRECOM Archipelago client, which writes the received item files these scripts read.

## Repository Layout

- `mod/scripts/*`

  | File | Description |
  | :--- | :---------- |
  | `recomRandoConnector.lua` | Gives received items (card sets, enemy cards, sleights, keys, friends), decides which world each floor's world-select screen offers, and sends checks. Writes the starting deck on a new game. |
  | `recomRandoExitHallEvents.lua` | Turns world journal entries into story progress and puts the right story fight in each Exit Hall. |
  | `recomRandoGameSettings.lua` | Applies attack power, turns off vanilla level-up sleights, and sets the Blizzard journal entry and friend flag. |
  | `recomRandoEXPMultiplier.lua` | Applies the EXP multiplier to the EXP gem table. |
  | `recomRandoDeathLink.lua` | Sends a death when Sora's HP hits 0 and knocks Sora out when a death is received. |
  | `recomRandoEnableDaysLocations.lua` | Marks 358/2 Days as watched so its locations are reachable. |
- `mod/scripts/io_packages/*`

  | File | Description |
  | :--- | :---------- |
  | `recom_seed_vars.lua` | Loads the seed mod's JSON files from `io_packages/json/`. |
  | `recom_settings.lua` | Reads values out of `settings.json`, with vanilla defaults when there is no seed. |
  | `recom_client_files.lua` | Reads and writes the files shared with the Archipelago client. |
  | `recom_locations.lua` | Location ID tables for every check the connector sends. |
- `build.py` / `generate_mod_yml.py`
  - Regenerate `mod.yml` from the files under `mod/`.

## Seed mod

The seed mod installs `scripts/io_packages/json/settings.json`:

```json
{
  "seed": "12345",
  "floor_worlds": [1, 7, 3, 9, 5, 6, 2, 8, 4, 10, 11, 12, 13],
  "card_sets": [[0, 1, 2], [13, 4]],
  "attack_power": 10,
  "exp_multiplier": 1
}
```

| Key | Contents |
| :-- | :------- |
| `floor_worlds` | 13 world IDs, one per floor from 1F to 13F. The world-select screen on that floor offers only this world, and only once its World Card has been received (Castle Oblivion: all friends found and Larxene II beaten). Floor 1 is always Traverse Town. |
| `card_sets` | Up to 20 card sets. Each is a list of card values (10-19 are premium). The Nth copy of a card set item gives set N, cycling. Set 1 is the starting deck. |
| `attack_power` | Sora's attack power (vanilla 10). |
| `exp_multiplier` | EXP multiplier. |

Without a seed mod the scripts use vanilla floors, one card set of values 0-9, attack power 10 and no EXP change.

## Files shared with the client

All files live in `%LOCALAPPDATA%\KHRECOM\` (or `$HOME/KHRECOM/` off Windows).

| File | Direction | Contents |
| :--- | :-------- | :------- |
| `AP_<n>.item` | client to game | One received item ID per file, numbered from 1. |
| `dlreceive` | client to game | Time of the last received DeathLink. |
| `send<location id>` | game to client | Empty file; one per checked location. |
| `victory` | game to client | Empty file once the victory item is received. |
| `dlsend<UTC time>` | game to client | Empty file; one per death sent. |

`setdata.cfg`, `worldorder.cfg`, `attackpower.cfg` and `xpmult.cfg` are no longer read; those values come from the
seed mod.

## Changes from KH-RECOM-AP-LUA
- Every address comes from the library, so the scripts no longer pick between `{egs, steam}` pairs.
- The one large connector is split into connector, Exit Hall and game settings scripts.
- Worlds are no longer forced onto floors by rewriting the floor-to-world table every 2 seconds. The world-select
  screen itself offers the seed's world for the current floor, so the game assigns it when the player picks the card.
- DeathLink and the Days flag now have addresses for both builds. The EGS DeathLink pointers and the Steam Days
  flag are worked out from the other build and still need checking in game (see the library README).

## Building/Making Changes
After changing scripts, run `python build.py` to regenerate `mod.yml`.
